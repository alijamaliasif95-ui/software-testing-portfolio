# Sample Test Cases

## Test Case 1: Login with Valid Credentials

**Test Case ID:** TC-001

**Module:** Login

**Objective:** Verify that a user can log in with valid credentials.

**Precondition:** The user has a valid account.

**Test Steps:**
1. Open the login page.
2. Enter a valid username.
3. Enter a valid password.
4. Click the Login button.

**Expected Result:** The user should log in successfully and reach the home page.

**Test Case ID:** TC-002

**Module:** Login
