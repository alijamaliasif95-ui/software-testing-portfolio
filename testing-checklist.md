# Manual Testing Checklist

## Login Page Testing

- [ ] Verify login with valid credentials.
- [ ] Verify login with invalid credentials.
- [ ] Verify behavior when username is empty.
- [ ] Verify behavior when password is empty.
- [ ] Verify the error message for invalid credentials.
- [ ] Verify that the Login button works correctly.

## User Interface Testing

- [ ] Verify that all buttons are visible.
- [ ] Verify that input fields are properly displayed.
- [ ] Verify that labels and messages are readable.
- [ ] Verify that the page layout is consistent.

## Bug Reporting

- [ ] Record clear steps to reproduce each bug.
- [ ] Write the expected result.
- [ ] Write the actual result after testing.
- [ ] Assign an appropriate severity.
- [ ] Retest after a fix is provided.

**Note:** This is a sample checklist. Mark items as completed only after performing the tests.
